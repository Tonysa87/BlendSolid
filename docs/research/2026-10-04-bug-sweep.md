# Headless bug sweep, 2026-10-04 (session 14)

Asked by the maintainer before the next build ("prenditi il tempo che serve per cercare altri bug"). Four
headless searches over branch `m3a` (throttled to 2 processes each after the first minutes): Blender operators
(~110 scenarios), sketch regions / Extrude / Revolve (~4750 cases), display mesh on 3a geometry (1500 parts),
grooves and paths (report pending). Scratch tools and repro scripts were in the session's scratchpad
(`sweep_blender/`, `sweep_regions/`, `sweep_mesh/`, `sweep_grooves/`); the repros that matter are copied into
tests as each bug is fixed.

Status: **fixed** (commit), **open**, or **won't fix** (reason). Fix one at a time, each with a test that fails
without it.
